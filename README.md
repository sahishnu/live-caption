# live-caption

A localhost-only, no-backend web app for operating live captions over a video feed.

See [`CONTEXT.md`](./CONTEXT.md) for the domain glossary, [`CLAUDE.md`](./CLAUDE.md)
for the project's non-negotiables, and `.scratch/live-caption/` for the spec and
tickets.

## Development

```bash
npm install
npm run dev       # Display View at /, Console at /admin
npm run test      # reducer + integration tests
npm run typecheck
```
